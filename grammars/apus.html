Tokens

→ production  ·  ↦ token terminal  ·  ⇢ discarded terminal  ·  ↝ trivia  ·  ↠ lexical token

Grammar of trivia

whitespace ⇢ /\s+/
comment ⇢ /\/\/.*/

Grammar of terminals

identifier ↦ /[_\p{XID_Start}][-\p{XID_Continue}]*/
literal ↦ /\"(?:[^\"\\]|\\.)+\"/
regex ↦ /\/(?!\*)(?:[^\/\\]|\\.)+\//

Grammar of attributes

action ⇢ /'(?:[^'\\]|\\.)*'/
pragma ↦ /@\p{XID_Start}\p{XID_Continue}*/
message ↦ /\^\^\^(?:(?s).*?)(?=\^\^\^|$)/

Productions

grammar → < production > { message }
production → [ pragma ] identifier ( : ( regex | literal ) . [ follow ] | - ( regex | literal ) . [ follow ] | -: selection . | = selection . )
selection → sequence { | sequence }
sequence → < factor [ ? | * | + ] | layout >
factor → terminal | [ selection ] | { selection } | < selection > | ( selection )
terminal → identifier [ exclusion ] | literal | regex | epsilon | empty
epsilon → ε
empty → ""

Grammar of annotations

exclusion → --- ( < literal > )
layout → >>| | |<< | <n> | <s> | >n< | >s<
follow → ( <+< | <-< | >+> | >-> ) ( < literal > )
